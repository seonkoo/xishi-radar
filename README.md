# 量窒息法 · 抄底选股

来源：NGA tid=47457683（2026-08-28），**经腾讯前复权日线实测校准**，非照抄。

核心：缩量窒息 + 小十字星（止跌）→ 次日放量红柱覆盖 → 介入。

## 口径
| 项 | 阈值 |
|---|---|
| 前期已下跌 | 近60日最高收盘 → 缩量日收盘 ≤ -15% |
| ① 量窒息 | 当日量 ≤ 近20日均量 × 0.7 |
| ② 小K线 | 当日涨跌幅 ∈ [-2.5%, +2.5%] |
| ③ 大红柱 | 次日涨幅 ≥2.5% 且 实体/振幅 ≥0.5 且 收盘覆盖前日 |
| ④ 放量 | 次日量 ≥ 缩量日量 × 1.3 |

时间轴：缩量日 q → 确认日 q+1 → **介入日 q+2（或确认日尾盘）**

## 回测（4985 只 / 2023-01~2026-09 / 27255 信号）
- 整体胜率 **48.8%**，均值 +1.07%，盈亏比 1.53 → **单靠形态无稳定优势**
- **关键因子是「实体饱满」**（≥0.8 → 51.6%），**不是「放量」**（≥2倍 46.3%、≥3倍 43.2% 反而更差）
- 最佳组合「跌深≤-30% + 缩量<0.5」：5日胜率 54.6%、10日 54.2% 均值 +2.14%
- 命中度评分与收益**不成正比**（80分以上反而最差）
- 逐年不稳定（2024 +3.28%，2026 -0.48%）→ 强依赖市场环境
